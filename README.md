# 🏆 TPSLAY 2026 — Студенческая премия группы ТПС-108

Стильный статический веб-сайт для пошагового голосования по 15 номинациям в эстетике **SLAY × РЖД**, готовый к деплою на **GitHub Pages** и интегрированный с **Google Таблицами**.

---

## ✨ Возможности
- **Дизайн SLAY × РЖД:** глубокий чёрный фон (`#0A0A0C`), стекломорфизм, неоновые красные акценты (`#E21A1A`), прогресс-бар в виде железнодорожного пути с поездом.
- **Mobile-first:** адаптация под iOS Safari (`100dvh`, `safe-area-inset`), удобная нижняя панель навигации.
- **Авторизация по 4-значному PIN-коду:** локальный список в `js/config.js` + проверка повторного голосования в Google Таблице и `localStorage`.
- **15 номинаций:** 3D-наклон карточек, подсветка выбора, модальное окно для видео-превью/мемов, автогенерация стильных аватаров-заглушек с инициалами, если фото ещё не загружено.
- **Экран проверки и итог:** сводка всех 15 выборов, чёрно-красно-белое конфетти и генерация PNG-карточки для сторис/чатов (`html2canvas`).
- **Демо-режим:** работает сразу «из коробки» без настройки сервера (голоса сохраняются в `localStorage` и выводятся в консоль браузера).

## ⚡ Как подключить Google Таблицу за 3 минуты

1. Создайте новую таблицу на [Google Таблицах](https://sheets.new) (например, назовите её **«TPSLAY 2026 — Голоса»**).
2. В верхнем меню откройте **Расширения → Apps Script**.
3. Удалите всё, что есть в редакторе, и целиком скопируйте туда код из файла [`google-apps-script/Code.gs`](google-apps-script/Code.gs).
4. Нажмите **Сохранить** (`Ctrl + S`).
5. В правом верхнем углу нажмите **Развернуть → Новое развертывание**.
6. Нажмите на шестерёнку рядом с «Выберите тип» и выберите **Веб-приложение (Web app)**.
7. Выставьте настройки:
   - **Запуск от имени:** *Я (ваш аккаунт Google)*
   - **У кого есть доступ:** *Все (Anyone)* — **обязательно!**
8. Нажмите **Развернуть**, подтвердите права доступа (если появится предупреждение безопасности Google, нажмите *Дополнительные настройки → Перейти на страницу проекта*).
9. Скопируйте полученный **URL веб-приложения** (заканчивается на `/exec`).
10. Откройте [`js/config.js`](js/config.js) и вставьте ссылку в поле `GOOGLE_SCRIPT_URL`:
    ```js
    GOOGLE_SCRIPT_URL: "https://script.google.com/macros/s/ВАШ_ID/exec",
    ```

После первого голоса скрипт сам создаст два листа:
- **`Votes`** — сырые голоса (дата, PIN, ФИО, выбор по всем 15 номинациям) с защитой от дублирования PIN.
- **`Live Results`** — автоматический подсчёт голосов и процентов по каждому кандидату.

## 🖼️ Куда загрузить фото, видео и как настроить PIN-коды

### 1. Фотографии и видео номинантов
- Положите фото в папку `assets/nominees/` с именами `nom1_1.jpg`, `nom1_2.jpg` ... `nom15_4.jpg` (или укажите свои пути/URL в [`js/data.js`](js/data.js)).
- Для видео-превью/мема положите `.mp4` в `assets/nominees/` и пропишите путь в поле `video: "assets/nominees/nom2_1.mp4"` у нужного кандидата в `js/data.js`.
- Если фото отсутствует, сайт автоматически сгенерирует стильную заглушку с инициалами кандидата.

### 2. Настройка списка PIN-кодов
Откройте [`js/config.js`](js/config.js) и отредактируйте словарь `VALID_PINS`:
```js
VALID_PINS: {
  "1042": "Иванов Иван",
  "2084": "Петров Пётр"
}
```
> Перед запуском реального голосования рекомендуется поставить `DEBUG_MODE: false` в `js/config.js`, чтобы скрыть кнопку сброса голоса на финальном экране.

## 🚀 Деплой на GitHub Pages

1. Создайте новый публичный репозиторий на GitHub (например, `tpslay-2026`).
2. Загрузите все файлы проекта в корень репозитория (через `git push` или кнопку **Add file → Upload files**).
3. Перейдите в **Settings → Pages**.
4. В разделе **Build and deployment** выберите:
   - **Source:** *Deploy from a branch*
   - **Branch:** `main` (или `master`), папка `/ (root)`
5. Нажмите **Save**. Через 1–2 минуты сайт откроется по адресу:
   `https://<ваш-логин>.github.io/tpslay-2026/`

## 🧪 Локальное тестирование
Просто откройте `index.html` в браузере (или через Live Server).  
Пока `GOOGLE_SCRIPT_URL` пустой, сайт работает в **демо-режиме** — можно использовать тестовые PIN-коды `1001`, `1002`, `1234` или `7777`. Итоговый JSON выводится в DevTools (`F12 → Console`).
